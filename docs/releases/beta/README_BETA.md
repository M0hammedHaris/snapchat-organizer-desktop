## Quick Start (3 Steps)

### 1. Download
Get the build for your OS from the [GitHub Releases](https://github.com/M0hammedHaris/snapchat-organizer-desktop/releases) page.

| Platform | File | Size |
|----------|------|------|
| macOS    | `Snapchat-Organizer-macOS.dmg` | ~120 MB |
| Windows  | `Snapchat-Organizer-Windows.zip` | ~150 MB |
| Linux    | `Snapchat-Organizer-Linux.tar.gz` | ~140 MB |

### 2. Install
- **macOS:** Open DMG → Drag to Applications → Right-click → Open
- **Windows:** Extract ZIP → Run `SnapchatOrganizer.exe` (see [Windows Guide](WINDOWS_INSTALLATION_BETA.md))
- **Linux:** Extract tarball → Run `./Snapchat Organizer`

### 3. Launch
- Complete the onboarding carousel on first launch
- Register for a free account or skip to use Free tier
- Press **F1** for help at any time

## System Requirements

- **macOS:** 10.13 (High Sierra) or later
- **Windows:** Windows 10 or later
- **Linux:** Ubuntu 20.04+ or equivalent
- **Disk Space:** ~200 MB for the application
- **No Python required** — standalone builds include everything

---

## Known Limitations

- Timezone conversion and overlay compositing tools are placeholders (coming soon)
- App is not code-signed (security warnings on first launch are expected and safe)
- First launch may be slow due to PyInstaller extraction
